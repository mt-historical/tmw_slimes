# Slimes

Adds lot of slimes to Luanti. Inspired by [TheManaWorld](https://www.themanaworld.org/).

## Dependencies

- Luanti/Minetest v5.10+
- MTG provided mods `default`, `fire`
- [Mobs Redo](https://codeberg.org/tenplus1/mobs_redo)
